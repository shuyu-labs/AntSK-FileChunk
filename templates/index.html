API 接口文档

1. 处理文件接口

POST /api/process-file
Content-Type: multipart/form-data

参数:
- file: 上传的文件 (必需)
- config: 配置JSON字符串 (可选)

响应: ProcessResponse

2. 处理文本接口

POST /api/process-text
Content-Type: application/x-www-form-urlencoded

参数:
- text: 文本内容 (必需)
- config: 配置JSON字符串 (可选)

响应: ProcessResponse

3. 获取默认配置

GET /api/config/default

响应: ChunkConfigRequest
